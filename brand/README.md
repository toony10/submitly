# submitly brand

| File | Use |
| --- | --- |
| `logo.svg` | Horizontal logo for light backgrounds |
| `logo-dark.svg` | Horizontal logo for dark backgrounds |
| `logo-mark.svg` | The mark on its own (64 × 64) |
| `icon.svg` | Favicon / app icon: the mark with a heavier stroke for small sizes |
| `favicon.ico` | 16, 32 and 48 px |
| `logo-mark-512.png` | Avatars (GitHub, npm, social) |

The apps use the same files: `apps/docs/app` and `examples/next-app/app` (`icon.svg`, `favicon.ico`, `apple-icon.png`, picked up by Next's file conventions) and `examples/vite-app/public`.

## Mark

A check whose long stroke ends in an arrowhead: the form is submitted and it succeeded, in one gesture. White, round caps and joins, on a rounded tile (radius 15 on a 64 grid).

## Colour

| Token | Hex |
| --- | --- |
| Gradient start (top left) | `#6366F1` |
| Gradient end (bottom right) | `#4338CA` |
| Accent (i-dot, light background) | `#4F46E5` |
| Accent (i-dot, dark background) | `#818CF8` |
| Ink (wordmark, light background) | `#0B0B1A` |

## Type

The wordmark is "submitly" set in [Geist](https://vercel.com/font) SemiBold (SIL Open Font License) with −3.5% tracking. It is converted to outlines, so the SVGs need no font. The dot of the "i" uses the accent colour.

## Don'ts

Don't recolour the tile outside the palette, stretch the logo, put the light logo on dark backgrounds, or set the wordmark in another typeface.
